# Python-Based Garden Simulator (v0.7.0)
DSA project: Python OOP, Stack, Queue, 2D list, Hierarchical Tree, Tree Traversal (BFS, Preorder, Inorder, Postorder) and Binary Search Tree.
Stack: HTML5/DOM/Vanilla JS, Tailwind (CDN), Lucide (CDN), Pyodide.

## Run
Open this folder in VS Code, install the **Live Server** extension, right-click `index.html` > *Open with Live Server*.
Code Editor tab > **Run All 1-7** > play.

`docs/JOURNAL.md` (technical journal with code evidence) and `docs/PROMPT_LOG.md` (prompt log + semantic versioning).
